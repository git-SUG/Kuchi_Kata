# くちのかたち れんしゅう

言語障害のある児童が、**カメラに映る自分の口の動きを見ながら発語練習**をするためのWebアプリです。
外部ライブラリ・サーバーを一切使わない単一HTMLファイルで動作し、GitHub Pages にそのまま公開できます。

- 対象：小学校（通級指導教室・特別支援学級・自立活動）
- 動作端末：iPhone / iPad（Safari）、Chromebook・タブレット（Chrome）、PC（Chrome / Edge / Safari）
- ファイル構成：`index.html` 1ファイルのみ

---

## 1. できること

| 機能 | 内容 |
|---|---|
| リアルタイム映像 | 端末のカメラ映像をそのまま表示。声の波形を映像に重ねて表示。鏡のように左右反転（ミラー）、口元を1〜3倍にズーム、口の位置を示すガイド枠、内側／外側カメラの切替 |
| 段階的なレベル | 母音 → 両唇音 → 舌尖音 → 奥舌・摩擦音 → 2音節語 → 3音節語 → 促音・拗音 → 短文 の8レベル |
| お手本 | 大きなかな表示＋母音別の口形イラスト＋発音のポイント。端末の音声合成による「お手本を聞く」ボタン |
| 得点化 | マイクの音量解析による自動評価（声の大きさ・発声時間・声の安定）＋口形の自己評価（◎○△） |
| レーダーチャート | 特別支援学校学習指導要領「自立活動」6区分に対応した観点別の達成度（直近10回の平均） |
| 棒グラフ | 縦軸＝その日の合計得点、横軸＝日付（直近14日） |
| データ保存 | 日付・時刻・レベル・ことば・観点別得点・累積得点を端末内に保存。CSV／JSON書き出し、JSON読み込み |
| メダル | 累積得点・連続練習日数・練習回数の3系統、計12種類 |
| 複数の学習者 | 児童ごとに記録を分けて保存。切替・追加・削除が可能 |

## 2. 公開のしかた（GitHub Pages）

1. GitHub で新しいリポジトリを作成します（例：`speech-practice`）。**Public** を選びます。
2. `index.html` をリポジトリの**直下**にアップロードします（`Add file` → `Upload files`）。
3. `Settings` → 左メニュー `Pages` を開きます。
4. **Source** を `Deploy from a branch`、**Branch** を `main` / `(root)` に設定し `Save`。
5. 1〜2分待つとページ上部に公開URLが表示されます。

```
https://（ユーザー名）.github.io/speech-practice/
```

このURLを児童用端末で開きます。ホーム画面に追加しておくとアプリのように起動できます。

> **重要：** カメラは `https://` でしか動作しません。ダウンロードしたHTMLをそのままダブルクリックして開く（`file://`）とカメラが起動しないため、必ずGitHub Pages経由のURLで開いてください。

## 3. 使いかた

1. 画面下の大きなボタン「**カメラを つける**」を押し、カメラとマイクの使用を**許可**します（初回のみ）。
2. 上部のチップでレベルを選び、「つぎの ことば」でお手本を選びます。
3. 「**はじめる**」→ 3・2・1のカウントのあと、自分の口を見ながら声を出します。
4. 結果画面で「くちの かたちは どうだった？」に ◎ ○ △ で答えます。誰かに聞いてもらった場合はチェックを入れます。
5. 「**きろくする**」で保存され、次のことばに進みます。
6. 同じレベルで **70点以上を3回**とると、次のレベルが開放されます。

「きろく」タブでグラフとメダル、「せってい」タブで学習者・カメラ・データ管理を操作します。

---

## 4. 評価の考え方

1回の練習ごとに、下記6観点をそれぞれ100点満点で算出し、その平均をその回の得点（0〜100点）としています。
観点は特別支援学校学習指導要領「自立活動」の6区分に対応させています。

| 自立活動の区分 | アプリ内表記 | 算出のもとになるもの |
|---|---|---|
| 健康の保持 | つづける力 | 連続練習日数 |
| 心理的な安定 | いよく・おちつき | その日の練習回数（最後までやり切った回数） |
| 人間関係の形成 | つたえあい | 「だれかに きいてもらった」の有無 |
| 環境の把握 | はんのうの はやさ | 「3・2・1」の合図のあと、どれだけすぐに声を出せたか（発声の立ち上がり） |
| 身体の動き | はっせいの力 | 発声を継続できた時間の割合と、声の安定度（音量のばらつき） |
| コミュニケーション | めいりょうさ | 声の大きさ＋口形の自己評価 |

口形の自己評価は ◎（ばっちり）＞○（できた）＞△（もうすこし）の順で、**必ず ◎ が最も高い得点**になります。
自己評価と自動測定値の一致度（振り返りの正確さ）は、「せんせい せってい」→「くわしい すうち」をオンにしたときのみ
参考情報として表示され、**得点には影響しません**。

### 自動測定の仕組み
音声認識は使用していません。録音開始前の0.5秒で環境ノイズを測り、その2.2倍を発声判定のしきい値として、
録音中の音量（RMS）から次の4つを算出します。

- **声の大きさ**：発声区間の平均音量
- **発声時間**：録音時間に対する発声区間の割合（55%以上で満点）
- **声の安定**：発声区間の音量のばらつき（変動係数）
- **立ち上がり**：録音開始から最初に声が出るまでの時間（前半15%以内で満点）

そのため、**構音の正確さそのものは自動判定しません**。構音の評価は児童の自己評価と指導者の見取りで補う設計です。
「せんせい せってい」→「くわしい すうち」をオンにすると、平均音量・発声時間比・しきい値の生データが表示されます。

## 5. データについて

- 記録は **その端末のブラウザ内（localStorage）にのみ保存**されます。サーバーへの送信は一切行いません。
- 映像・音声は**録画・録音・保存されません**。画面表示と音量測定にのみ使用し、その場で破棄されます。
- 端末を替えるとき、ブラウザの履歴・サイトデータを消去するときは、事前に「せってい」→ **JSONで 書き出す** でバックアップしてください。移行先で「JSONを 読み込む」を実行すると記録が復元されます（重複分は自動的に除外されます）。
- **CSVで 書き出す** を使うと、Excel等で日付・観点別得点まで含めた一覧を確認できます（個別の指導計画の記録や保護者への説明資料に利用できます）。

### CSVの列
`日付, 時刻, なまえ, レベル, ことば, 得点, 健康の保持, 心理的な安定, 人間関係の形成, 環境の把握, 身体の動き, コミュニケーション, 音量, 発声時間, 安定, 立ち上がり, 口形自己評価, 聞いてもらった`

## 6. 学校の端末で使うときの確認事項

管理されたChromebookやiPadでは、次の設定が必要になる場合があります。

1. **Webフィルタの許可** — `*.github.io` がフィルタでブロックされていないか確認してください。ブロックされている場合は情報担当・教育委員会に許可を依頼します。
2. **カメラ／マイクの権限** — Google管理コンソールのユーザー設定でカメラ・マイクが禁止されていないか確認してください。ブラウザ側ではアドレスバーの鍵アイコンから、そのサイトのカメラ・マイクを「許可」に設定できます。
3. **音量** — 端末のマイク入力が有効になっているか。マイクが使えない場合も映像と自己評価だけで練習・記録は可能です（自動測定は行われません）。

---

## 7. うまく動かないとき

| 症状 | 確認すること |
|---|---|
| カメラが映らない | URLが `https://` で始まっているか。ブラウザの許可ダイアログで「許可」を押したか。他のアプリ（Meet等）がカメラを使用中でないか |
| 得点が出ない・声の波が動かない | マイクが許可されているか。端末を口元に近づける。「せってい」で録音時間を長くする |
| お手本の声が出ない | 端末に日本語の音声合成が入っていない場合は使用できません。他の機能には影響しません |
| 次のレベルが選べない | 前のレベルで70点以上を3回とると開放されます。すぐ使いたい場合は「せんせい せってい」→「ぜんレベル かいほう」をオンにします |
| 記録が消えた | ブラウザのサイトデータ消去、シークレットモードでの使用、iOSの長期未使用によるデータ削除が原因です。定期的にJSON書き出しをしてください |

## 8. カスタマイズ

`index.html` をテキストエディタで開き、`const LEVELS = [` の部分を編集すると、練習することばを変更できます。

```js
{n:"レベル1", t:"ぼいん", hint:"おおきく くちを あける",
 items:["あ","い","う","え","お"]},
```

- `n` … レベル名　`t` … レベルの内容　`hint` … 画面に出す発音のポイント　`items` … 練習することば（ひらがな）
- 児童の名前や身近な語（「せんせい」「きゅうしょく」など）を `items` に足すと意欲が高まります。
- メダルの獲得条件は `const MEDALS = [` の `need`（必要な点数・日数・回数）で調整できます。
